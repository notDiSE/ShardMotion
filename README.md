1. Open your Unity project and select **Assets > Import Package > Custom Package...**
2. Select the `ShardMotion_vX.X.X.unitypackage` file.
3. In the import window, choose whether to include the samples (`Examples/` folder).
4. Click the **Import** button in the bottom right corner.
5. If you included the samples, the plugin may request additional packages:
   - **Animation Rigging** — humanoid animation
   - **Text Mesh Pro Essentials** — Game Example
6. After importing, the initial setup window will open automatically.
   > The window can be reopened at any time via **Tools > ShardMotion > Quick Setup**.
7. Click the **"Setup Global Settings"** button (next to the red cross) to create the configuration file.

The plugin is now installed. Usage instructions are available directly in the Quick Setup window — click **Open Manual**.
