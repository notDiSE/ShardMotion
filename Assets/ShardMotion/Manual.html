ShardMotion – Manual

ShardMotion is a Unity plugin that tracks the movement of physical objects using printed ArUco markers and one or more webcams. No specialized hardware or external software is required.

What You Need

  • A Unity project with ShardMotion installed
  • A webcam connected to your computer
  • Printed ArUco markers - any printer, plain paper is fine, but make sure, the printed marker has a white border around the code, that is at least one grid cell wide - otherwise the tracking could be unstable

First Launch

When you open a Unity project with ShardMotion for the first time, a setup window appears automatically. Click the button to create the plugin's settings file. The plugin will not work without it.

The setup window can be open at any time using Tools > ShardMotion > Quick Setup

Basic Setup

1. Add a Camera

Create a new GameObject (or use an existing Unity Camera) and add the TrackingCamera component to it.

In the Inspector, select which physical camera to use from the dropdown menu.

Two startup options:

  • Start Automatically – the camera starts by itself when Play mode begins. Enable this before entering Play mode.
  • Manual start – leave it off and start the camera from the Control Panel or from your own script during Play mode.

2. Add a Tracked Object

Add the ArUcoTarget component to the virtual object you want to move.

Configure it:

  • Marker ID – the number printed on the physical marker. Must match exactly.
  • Marker Size – physical size of the marker in meters (e.g. 0.05 for a 5 cm marker).
  • Position Offset – offset from the object's pivot point if the marker is not centered on the object.
  • Rotation Offset – rotation of the marker relative to the object's orientation.

A visual preview of the marker placement is shown in the Scene view to help you align it correctly.

If you want the target to register itself automatically when Play mode starts, enable Auto Register.

Starting Tracking

Everything below happens inside Play mode.

If you have enabled Start Automatically on your cameras and Auto Register on your targets, tracking starts on its own — nothing else is needed.

If you are starting things manually:

  1. Open the Control Panel: ShardMotion → Control Panel
  2. Click Start All Cameras (or start individual cameras)
  3. Click Register All Targets

Once running, the TrackingCamera Inspector shows a live preview. Detected markers are highlighted with their ID and orientation arrows.

Camera Calibration (Recommended)

Camera calibration improves tracking accuracy by measuring the lens properties of your camera. It only needs to be done once per physical camera.

Camera calibration is the only step that does not require Play mode. Everything else in this manual happens in Play mode.
  1. In the TrackingCamera Inspector, click Camera Calibration.
  2. A calibration window opens with a live camera preview.
  3. Hold a chessboard pattern in front of the camera (included with the plugin). Move it to different positions and angles.
  4. Take at least 5 photos using the Take Snapshot button. More photos from varied angles = better result.
  5. Click Finish Calibration. The parameters are saved automatically.

You do not need to redo calibration if the camera is moved to a new position.

Multiple Cameras

Add a TrackingCamera component for each physical camera. When using more than one camera, you must calibrate the spatial positions of the cameras so the plugin knows where they are relative to each other. This is done in Play mode.

Calibration Cube

You need a physical cube with ArUco markers on each of its four sides. You can make one from any rigid material by attaching printed markers. A 3D-printable version is included with the plugin.

Setting Up the CalibrationDevice

  1. In your Unity project, create or locate the CalibrationDevice ScriptableObject.
  2. Set the marker ID for each face of the cube.
  3. Set Cube Size – the physical side length of the cube in meters.
  4. Set Marker Size – the physical size of the markers on the cube in meters.

Running Space Calibration

Do this in Play mode, after cameras are started.

  1. Place the calibration cube in the center of the tracking area.
  2. Open the Control Panel and select the CalibrationDevice in the designated field.
  3. Click Start Calibration.
  4. Wait for all cameras to show green (calibration successful). Yellow = in progress, red = failed.
  5. Once all cameras are green, you can remove the cube.

The cube's position becomes the origin point (0, 0, 0) of the tracking space.

Recording Motion to Animation

  1. In the Scene hierarchy, place all ArUcoTarget objects you want to record under one parent GameObject.
  2. Add the Record component to that parent object.
  3. In Play mode, start tracking, then start recording.
  4. When done, stop recording. You will be prompted to enter a file name and path. The animation clip is saved to your Assets folder.

Global Settings

The plugin settings are stored in a ScriptableObject file inside the Resources/ folder. Three values:

SettingWhat it does
DictionaryThe ArUco marker dictionary (determines marker grid size). Must match the markers you have printed. When in doubt, leave the default.
Position SmoothingSmooths out jitter in position (0–1). Higher = smoother but slower response.
Rotation SmoothingSame as above, but for rotation.

These settings are global — they apply to all cameras and targets in the scene. All cameras must use the same dictionary, otherwise tracking data will be inconsistent across cameras.

TrackingCameraAdd to any GameObject (ideally a Unity Camera). Reads from a physical webcam and detects markers.
ArUcoTargetAdd to the virtual object you want to track. Links a marker ID to that object.
RecordAdd to the parent of tracked objects. Records their movement into a Unity animation clip.
CalibrationDeviceScriptableObject describing the calibration cube. Required only when using multiple cameras.

Troubleshooting

Marker is not detected

  • Check that the printed Marker has wide enough white border around the code.
  • Check that the Marker ID in ArUcoTarget matches the printed marker.
  • Check that the Dictionary setting matches the type of markers you printed.
  • Improve lighting — the marker needs to be clearly visible and not overexposed.
  • Make sure the target is registered (either via Auto Register or manually from the Control Panel).

Object shakes or jitters

  • Increase Position Smoothing and Rotation Smoothing in the plugin settings.

Camera does not start

  • Make sure the camera is connected and not in use by another application.
  • In the TrackingCamera Inspector, re-select the camera from the dropdown.

Space calibration fails or turns red

  • Make sure the calibration cube is visible to the camera during calibration.
  • Make sure the CalibrationDevice settings match your physical cube exactly (marker IDs, sizes).
