Animation Recording

This example demonstrates how to record animations using ShardMotion.

The recording must be made in playtime.

How to Record:
    1. Enable CorrectRecordSetup or AlsoCorrectRecordSetup
            (both work and showcase different recording configurations)
    2. Click the Record button on the corresponding Setup
    3. Stop the recording - you will be prompted to save the animation clip
    4. Play back the clip on the same Setup it was recorded on

Setups:
CorrectRecordSetup     - multiple objects recorded with one Record component (each object with ArUcoTarget components will be recorded)
AlsoCorrectRecordSetup - single object recording
